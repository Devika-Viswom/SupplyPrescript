# Notebooks

## Overview

This folder contains all Jupyter notebooks used during the development of SupplyPrescript.

The notebooks follow the complete machine learning workflow from data understanding to model deployment.

## Notebook Sequence

### 1_data_understanding.ipynb

Initial dataset exploration:

- Dataset structure
- Data types
- Summary statistics
- Missing values

---

### 2_data_cleaning.ipynb

Data preprocessing:

- Handling missing values
- Duplicate removal
- Data quality checks

---

### 3_eda.ipynb

Exploratory Data Analysis:

- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Visualizations
- Business insights

---

### 4_feature_selection.ipynb

Feature engineering and selection:

- Date features
- Route features
- Risk categorization
- Reliability categorization
- Encoding

---

### 5_disruption_classifier_model.ipynb

Classification model development:

- Model training
- Evaluation
- Feature importance
- Hyperparameter tuning

---

### 6_lead_days_regressor_model.ipynb

Regression model development:

- Lead time prediction
- Model evaluation
- Error analysis

---

### 7_business_analysis.ipynb

Business-focused analysis:

- Operational insights
- Risk analysis
- Performance evaluation

---

### 8_model_pipeline.ipynb

Pipeline creation and export:

- Final preprocessing pipeline
- Model serialization
- Joblib export
